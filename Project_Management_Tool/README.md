# Project Management Tool

A full-stack Project Management Tool developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- User authentication
- Project management
- Task management
- Task status tracking
- Team collaboration
- REST API
- MongoDB database
- Real-time communication with Socket.IO

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT
- CORS
- dotenv
